# 📞 FaleMais - Calculadora de Custo de Chamadas

Este projeto permite calcular o custo de chamadas telefônicas com base em DDDs e planos.

## 🚀 Tecnologias Utilizadas
- **Frontend:** Angular + Bootstrap
- **Backend:** .NET 8 + C#
- **Banco de Dados:** SQLite (opcional)

## 🛠 Como Rodar o Projeto
### 📌 Backend
```bash
cd FaleMais
dotnet run

### Frontend
```bash
cd fale-mais-frontend
npm install
ng serve --open
