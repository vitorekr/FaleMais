﻿# FaleMais - Calculadora de Custo de Chamadas

## Tecnologias Utilizadas
- **Frontend:** Angular + Bootstrap
- **Backend:** .NET 8 + C#

## Como Rodar o Projeto
### Backend
```bash
cd fale-mais-backend
dotnet run
```
### Frontend
```bash
cd fale-mais-frontend
npm install
ng serve --open
```

### Testes
```bash
cd fale-mais-backend
dotnet test
```
