## Tecnologias Utilizadas
- **Frontend:** Angular + Bootstrap
- **Backend:** .NET 8 + C#
- **Docker**

## Como Rodar o Projeto
### Docker
```bash
docker-compose up --build

Para acessa o Swagger acesse:
http://localhost:5000/swagger

Para acessar o frontend acesse:
http://localhost/
```

### Testes
```bash
cd fale-mais-backend
dotnet test
```
